# List Sharma-Pukkala biomass species and parameters

Lists the 21 named species and two explicit miscellaneous groups
available for the Sharma and Pukkala (1990) air-dry biomass method.

## Usage

``` r
sharma_pukkala_species()
```

## Value

A data frame containing supported species, biomass parameters, air-dry
density, sample size, and observed DBH calibration range.
