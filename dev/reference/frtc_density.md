# Inspect FRTC-recommended densities for total biomass

Inspect FRTC-recommended densities for total biomass

## Usage

``` r
frtc_density(species = NULL, dbh = NULL)
```

## Arguments

- species:

  Optional supported species identifier or Nepali name.

- dbh:

  Optional DBH in cm. When supplied with \`species\`, return the density
  applied by the package for that tree.

## Value

A density-rule table, or a one-row applied-density result.
