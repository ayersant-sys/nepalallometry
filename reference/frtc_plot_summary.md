# Summarize FRTC-supported biomass and carbon by plot

Summarize FRTC-supported biomass and carbon by plot

## Usage

``` r
frtc_plot_summary(data)
```

## Arguments

- data:

  Output from \[estimate_frtc_biomass()\].

## Value

One row per plot, with biomass and carbon in Mg/ha, model coverage, and
calibration-range/extrapolation counts.
